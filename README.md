## README
# A.C.E Ancient Civilizations Eras 
FBLA Mobile App Dev 2025

This project was done for FBLA by Reilly Hawkins & Leah Niebuhr. It was designed to encourage students in grades 4th-8th to learn more about the ancient world. It has an interactive crossword puzzle and quiz as well a scoreing features to keep track of progress. Currently, we have 5 civilizations to learn about, but we hope to add more in the future! We used React Native as a Framework as well as Expo.
